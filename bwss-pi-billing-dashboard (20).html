Connect the PI / Billing workbook

This dashboard reads and writes to a dedicated Google Sheet for attorney follow-up, lien reference info, and pending records requests — plus a read-only lookup against the existing Patient MASTER sheet for reconciliation.

First connection will also request Gmail read-only access on Frontdesk@bewellarvada.com, used only to scan for attorney/lien record-request emails. No patient data is written anywhere outside this workbook.
